# WARUNG-STOCK: Smart Inventory Management 📦

[![Platform](https://img.shields.io/badge/Platform-Android-green?style=flat-square)](#)
[![Framework](https://img.shields.io/badge/Framework-React_Native-61DAFB?style=flat-square&logo=react)](#)
[![Database](https://img.shields.io/badge/Database-SQLite%2FMySQL-4479A1?style=flat-square&logo=sqlite)](#)

**WARUNG-STOCK** adalah aplikasi manajemen inventaris berbasis mobile yang dirancang khusus untuk membantu pelaku UMKM, seperti warung makan dan toko grosir, dalam mengelola stok bahan baku secara digital dan efisien.

---

## 📝 Latar Belakang

Banyak warung makan lokal masih mengandalkan pencatatan manual atau ingatan untuk memantau stok bahan baku seperti beras, telur, dan minyak. Hal ini sering menimbulkan masalah seperti:

- **Stok Habis:** Kehabisan bahan baku di saat jam sibuk.
- **Pemborosan:** Bahan baku kedaluwarsa karena tidak terpantau dengan baik.
- **Mobilitas Tinggi:** Pemilik membutuhkan alat praktis yang bisa diakses langsung di dapur atau pasar.

## 🚀 Fitur Utama

- **Manajemen Stok:** Input data bahan baku berdasarkan nama, jumlah, satuan, dan kategori.
- **Peringatan Stok Rendah:** Indikator warna merah atau notifikasi jika stok berada di bawah batas minimum.
- **Log Barang Masuk/Keluar:** Riwayat penggunaan harian untuk memantau pola konsumsi.
- **Pemantauan Kedaluwarsa:** Membantu mengurangi risiko kerugian akibat bahan rusak.

## 🛠️ Tech Stack

- **Bahasa / Framework:** React Native
- **Database:** SQLite / MySQL
- **Desain UI/UX:** Figma
